## 📌 Project Overview

This project performs an end-to-end analysis of E-Commerce Sales data using Python. The objective is to derive actionable business insights through data cleaning, exploratory data analysis (EDA), visualization, and KPI reporting.

## 🚀 Key Features

- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Revenue Analysis
- Customer Segmentation
- Category Performance Analysis
- Advanced Python Concepts
- Data Visualization using Matplotlib & Seaborn

## 🛠 Tech Stack

- Python
- Pandas
- NumPy

- Seaborn
- Jupyter Notebook
